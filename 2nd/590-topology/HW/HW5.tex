\begin{enumerate}[(a)]
    \item Shown in class the basis for the product topology of $\R^\omega$ are of the form 
    \[U_1 \times U_2 \times \dots \times U_n \times \R \times \R \times \dots\]
    s.t. $U_i$ are open sets in $\R$. Let $x \in \R^\omega$. Let $U$ be an open neighborhood of $x$. It suffices to show for just a basis set, so let $U$ just be a basis element.

    Define a sequence $y=(y_1,y_2,\dots)$ s.t.
    \begin{equation*}
        y_i=\begin{cases}
            x_i, \quad \t{if } 1 \leq i \leq n,\\
            0, \quad \t{if } i > n.
        \end{cases}
    \end{equation*}
    Thus, $y \in U \cap R^\infty$

    Thus, every open neighborhood of every point $x \in \R^\omega$ intersects $\R^\infty$. Thus $\overline{\R^\infty}=\R^\omega$ in the product topology.

    \item Let $x=(x_1,x_2,\dots) \notin \R^\infty$ this means that there is no $n \in \N$ s.t. it is all zeros after. Thus consider the neighborhood of $x$
    \[U=\prod_{i=0}^{\infty}U_i\]
    s.t.
    \begin{equation*}
        U_i=\begin{cases*}
            (-1,1), \quad \t{if } x_i=0,\\
            (x_i-\epsilon_i, x_i+\epsilon_i), \quad \t{if } x_i \neq 0.
        \end{cases*}
    \end{equation*}
    $\epsilon_i=|x_i|/2$. This makes sure that the interval does not intersect zero.

    This is open since it is made up of open intervals of $\R$.

    Let $y \in U$. By definition of $U$, for each $n$ we have $y_n \in U_n$.

    If $x_n \neq 0$ then $y_n \neq 0$, and since there is no $n$ where it ends it infinitely many zeros this means $y$ can't also have infinitely many zeros. Thus $y \notin \R^\infty$

    Thus, $U \cap \R^\infty=\emptyset$.

    Thus, $\overline{\R^\infty}=\R^\infty$, since any point outside we can create a neighborhood that does not intersect $\R^\infty$

    \item Let $C=\{x=(x_1,x_2,\dots) \in \R^\omega \mid (x_n)\to 0\}$
    
    Let $x \notin C$ this means $x_n$ does not converge to 0. Thus, there is a $\epsilon_0>0$ s.t. for all $N \in \N$ there is some $n \geq N$ with
    \[d(x_n,0)\geq \epsilon_0\]
    Fix $\epsilon=\min\{1,\epsilon_0/2\}$. Consider the open ball
    \[B(x,\epsilon)=\{y \in \R^\omega \mid d(x,y) < \epsilon\}\]
    since $\epsilon < 1$ we get that 
    \[B(x,\epsilon)=\{y \in \R^\omega \mid d(x_n,y_n) < \epsilon \t{ for all } n \in \N\}\]
    Assume for contradiction that $y  \in B(x,\epsilon) \cap \R^\infty$

    Fix $M \in \N$ s.t. $y_n=0$ for all $n \geq M$.

    However, since $x \notin C$ we have that $d(x_n,0)\geq \epsilon_0$ for infinitely many $n \in \N$ thus pick index $n_0 \geq M$ s.t.
    \[d(x_{n_0} \geq \epsilon_0)\]
    Then since $y_{n_0}=0$ we have
    \[d(x_{n_0},y_{n_0})=d(x_{n_0},0) \geq \epsilon_0 > \epsilon\]
    Thus $y \notin B(x,\epsilon)$ which is a contradiction therefore $x \notin \overline{\R^\infty}$, since there is a neighborhood of $x$ that does not intersect $\R^\infty$

    Let $x \in C$ thus $(x_n) \to 0$

    Let $U$ be an open neighborhood of $x$. Thus there exists an $\epsilon > 0$ s.t. 
    \[B(x,\epsilon) \subseteq U\]
    If $\epsilon >1$ just fix $0 < \delta < 1$ s.t. $B(x,\delta) \subseteq B(x,\epsilon) \subseteq U$, so WLOG let $\epsilon <1$.

    Since $(x_n) \to 0$ there is an $N \in \N$ s.t. for all $n \geq N$ we have
    \[d(x_n,0) < \epsilon/2\]

    Define a sequence $y=(y_1,y_2,\dots)$ s.t.
    \begin{equation*}
        y_n=\begin{cases}
            x_n, \quad n < N,\\
            0, \quad n \geq N.
        \end{cases}
    \end{equation*}

    For $n < N$ we have that $y_n=x_n$ so $d(x_n,y_n)=0 < \epsilon$

    For $n \geq N$ we have that $y_n=0$ and since $d(x_n,0) < \epsilon/2$ we have that
    \[d(x_n,y_n)=d(x_n,0)<\epsilon/2<\epsilon\]
    Thus for all $n \in \N$ we have $d(x_n,y_n) < \epsilon$ so
    \[d(x,y)=\sup_{n \in \N}d(x_n-y_n)< \epsilon\]
    Thus $y \in B(x,\epsilon) \subseteq U$

    Thus $x \in \overline{\R^\infty}$ 

    Thus $\overline{\R^\infty}=C$
\end{enumerate}

    \[d(f_n(x),f(x)) < \epsilon/3\]

    \[d(f(x),f(z)) \leq d(f(x),f_N(x))+d(f_N(x),f_N(z))+d(f_N(z),f(z)) < \epsilon/3+\epsilon/3+\epsilon/3=\epsilon\]

Separate Proof:

Consider $f: \R^n \to \R^n$ s.t. $f(x)=x+a$ for some $a \in \R^n$. This is continuous since adding is continuous and $a$ is a constant function which is continuous. Consider the function $g: \R^n \to \R^n$ s.t. $g(x)=x-a$. This is an inverse for $f$ and same reason it is continuous. Thus, this is a homeomorhphism.

Let $x \in \R^n$ s.t. $n \geq 2$. Now by the proof above we showed that translation is a homeomorhphism thus WLOG let $x=0$.

Consider $\R^n \setminus \{0\}$

Consider the straight-line path $l(x)=(1-x)a+xb$ this is continuous since we are just adding and multiplying. Also this is a path since $l(0)=a$ and $l(1)=b$.

If $0$ is not in our image then we are good, and we get a continuous path from $a,b$ in $\R^n \setminus \{0\}$

If $0$ is in our image then pick any point $c \in \R^n$ s.t. there is no line that connects $a,b,c$. This is possible since $n \geq 2$.

Now consider the two line paths

\[l_1(x)=(1-x)a+xc\]
\[l_2(x)=(1-x)c+xb\]
for $x\in [0,1]$

Now set $l(x)$ to be
\begin{equation*}
    l(x)=\begin{cases*}
        l_1(2x) \quad \t{if } (0 \leq x \leq 1/2),\\
        l_2(2x-1) \quad \t{if } (1/2 \leq x \leq 1),\\
    \end{cases*}
\end{equation*}

Using the pasing lemma we can see it is continuous on $[0,1/2]$ and $[1/2,1]$, and for the intersection since the two functions agree we know that $l$ is continuous.

Thus this is a path in $\R^n \setminus \{0\}$

Thus $\R^n \setminus \{0\}$ is path connected, and therefore connected. Thus $\R^n \setminus \{x\}$ is connected for all $x \in \R^n$

        Assume: There exists a homeomorphism
        \[
        f:(0,1)\to (0,1].
        \]
        Since \(1\) is an element of \((0,1]\), there must be some \(x_0\in (0,1)\) with
        \[
        f(x_0)=1.
        \]
        
        - In \((0,1]\), remove \(1\):
          \[
          (0,1]\setminus\{1\}=(0,1).
          \]
          This set is connected, since we can define $f':[0,1] \to (0,1)$ by $f(x)=(1-x)a+xb$ thus $(0,1)$ is path connected thus connected.
        
        - In \((0,1)\), remove \(x_0\):
          \[
          (0,1)\setminus\{x_0\}=(0,x_0)\cup (x_0,1).
          \]
          This is the union of two disjoint, nonempty open intervals and is therefore disconnected.
        
        Since $f$ is a homeomorhphism we know that it's restriction is still a homeomorhphism thus $(0,1) \setminus \{x_0\} \cong (0,1] \setminus \{1\}$ However, homeomorphisms must preserve connectedness, \(f\) would force a connected space to be homeomorphic to a disconnected one. This contradiction shows that no homeomorphism exists between \((0,1)\) and \((0,1]\).
        
        \item \((0,1)\) vs. \([0,1]\)
        
        Assume: There exists a homeomorphism
        \[
        h:(0,1)\to [0,1].
        \]
        
        Since \(1\) is an element of \((0,1)\), there must be some \(x_0\in (0,1)\) with
        \[
        h(x_0)=1.
        \]
        
        - In \([0,1]\), remove \(0\):
          \[
          [0,1]\setminus\{0\}=(0,1],
          \]
          which is connected by same logic as above.
        
        - In \((0,1)\), remove the point \(x_0\):
          \[
          (0,1)\setminus\{x_0\}=(0,x_0)\cup (x_0,1),
          \]
          which is disconnected.
        
        Again, we have a homeomorphism sending a disconnected space to a connected space, which is impossible.
        
        Thus, no homeomorphism exists between \((0,1)\) and \([0,1]\).
    
        \item \((0,1]\) vs. \([0,1]\)

        \item If $x \in \partial(A)=\overline{A} \cap \overline{X \setminus A} \implies x \in \bar{A}$
        
        Thus $int(A) \cup \partial(A) \subseteq \bar{A}$.
    
        \item Let $x \in \bar{A}$.
        
        \item If $x \notin \overline{X \setminus A}$ then $x \in X \setminus \overline{X \setminus A} \subseteq int(A) \cup \partial(A)$
        
        \item If $x \in \overline{X \setminus A} \implies x \in \overline{X \setminus A} \cup \bar{A} \subseteq int(A) \cup \partial(A)$
    \end{itemize}
    Thus $int(A) \cup \partial(A)=\bar{A}$

    Thus $\partial(A)=\bar{A} \setminus A$ if $A$ is open.

We know from earlier homework that the determinant function
\[
\det \colon GL(n,\mathbb{R}) \to \mathbb{R}
\]
is continuous. Consider the sets
\[
\det^{-1}\bigl((-\infty, 0)\bigr) = \{A \in GL(n,\mathbb{R}) \mid \det(A) < 0\}
\]
and
\[
\det^{-1}\bigl((0, \infty)\bigr) = \{A \in GL(n,\mathbb{R}) \mid \det(A) > 0\}.
\]
Since \((-\infty, 0)\) and \((0, \infty)\) are open in \(\mathbb{R}\) and the determinant is continuous, these preimages are open in \(GL(n,\mathbb{R})\).

Moreover, these two sets are disjoint (because no matrix can have both a positive and a negative determinant) and their union is the whole set \(GL(n,\mathbb{R})\). Hence, \(GL(n,\mathbb{R})\) is not connected.
